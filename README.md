# Арчік — голосовий помічник (Android)

Слухає у фоні, розуміє українську, відповідає голосом, керує телефоном і спілкується як друг.

## Що вміє

Керування телефоном (без інтернету):
- «Арчік, відкрий Вайбер / Ютуб / Камеру / Налаштування»
- «Арчік, подзвони мамі» (за іменем із контактів або за номером)
- «Арчік, напиши мамі смс привіт, я скоро буду», «напиши Івану у Вайбері що запізнююсь»
  (повідомлення готується, натисніть «Надіслати» на екрані)
- «Арчік, постав будильник на 7:30», «розбуди мене завтра о шостій ранку», «таймер на 10 хвилин»
- «Арчік, увімкни ліхтарик» / «вимкни ліхтарик»
- «Арчік, гучніше», «тихіше», «гучність 50 відсотків», «вимкни звук»
- «Арчік, пауза», «наступна пісня», «увімкни музику» (у будь-якому плеєрі)
- «Арчік, відкрий Wi-Fi» (Android не дозволяє вмикати Wi-Fi самостійно, відкривається панель)
- «Арчік, скільки заряду», «котра година», «яке сьогодні число»
- «Арчік, прокладі маршрут до Львова», «загугли рецепт борщу»
- «нагадай завтра о 7 про зарядку», «запиши нотатку ...», «додай молоко у список покупок»
- «скасуй будильник», «які нагадування»
- «стоп» або «відбій» вимикає Арчіка

Розмова як з другом (потрібен ключ ШІ): будь-яке інше запитання чи розмова. Після відповіді Арчік
ще кілька секунд слухає без слова «Арчік», тож можна продовжувати розмову.

## Перше налаштування

1. Відкрийте Арчіка, дайте дозволи на мікрофон і сповіщення.
2. Натисніть «Дозволити контакти й дзвінки» (для дзвінків і повідомлень за іменем).
3. Натисніть «Дозволити відкривати програми з фону» й увімкніть перемикач для Арчіка.
   Без цього, коли екран вимкнений, програми відкриваються через сповіщення.
4. Натисніть «Не обмежувати батарею» (щоб Android не вимикав Арчіка у фоні).
5. У налаштуваннях вставте ключ для ШІ (Gemini безкоштовно: aistudio.google.com, або Claude).
6. Натисніть «Запустити Арчіка» і скажіть «Арчік» та команду.

## Як зібрати APK (без папок, з телефону чи комп'ютера)

1. На github.com відкрийте свій репозиторій, Add file → Upload files, завантажте `project.zip`. Commit.
2. Файл `.github/workflows/build.yml` уже має бути в репозиторії (створюється один раз через Create new file).
3. У вкладці Actions зачекайте зелену галочку, завантажте архів `archik-apk`, розпакуйте й встановіть `app-debug.apk`.

Увага: ця версія підписана постійним ключем. Якщо раніше був встановлений Арчік зі старого збирання,
один раз видаліть його (Налаштування → Програми → Арчік → Видалити), потім встановіть нову. Ключ ШІ
доведеться вставити знову. Наступні оновлення вже встановлюватимуться поверх.

## Обмеження

- Постійне слухання розряджає батарею швидше, а в шторці завжди видно сповіщення Арчіка.
- Розпізнавання мовлення дає застосунок Google (потрібен інтернет і оновлений Google).
- Для голосу потрібен український голос: Налаштування → Мова → Синтез мовлення.
- Wi-Fi, Bluetooth і надсилання повідомлень Android не дозволяє робити самостійно, потрібне ваше торкання.
- Після перезавантаження телефону відкрийте Арчіка й запустіть його знову. Будильники відновлюються самі.
