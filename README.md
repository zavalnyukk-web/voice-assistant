# Арчік — голосовий помічник (Android)

Застосунок слухає у фоні, розуміє українську, відповідає голосом.

## Що вміє

Без інтернету (локальні команди):
- «нагадай завтра о сьомій ранку про зарядку», «нагадай через 30 хвилин зателефонувати»
- «таймер на 10 хвилин»
- «запиши нотатку ...», «прочитай мої нотатки», «очисти нотатки»
- «додай молоко і хліб у список покупок», «що в списку покупок», «очисти список покупок»
- «котра година», «яке сьогодні число»
- «стоп» — вимкнути помічника

З інтернетом і ключем API: відповіді на будь-які запитання (модель claude-haiku-5-5).

## Як користуватися

1. Запустіть застосунок, дайте дозвіл на мікрофон і сповіщення.
2. Натисніть «Запустити Арчіка». У шторці з'явиться постійне сповіщення.
3. Скажіть «Арчік» і після паузи команду. Або одразу: «Арчік, котра година».
4. Без слова-активації: вимкніть перемикач у налаштуваннях і натискайте «Слухати» у сповіщенні.
5. Для відповідей ШІ вставте ключ API в налаштуваннях (отримується на console.anthropic.com, оплата за використання).
6. Щоб не вимикався у фоні: натисніть «Не обмежувати батарею» і дозвольте.

## Як зібрати APK (без Android Studio, з Windows)

1. Зайдіть на github.com, створіть новий репозиторій (кнопка New).
2. У ньому натисніть «uploading an existing file» і перетягніть ВСЕ вміст цієї папки (разом з прихованою папкою `.github`). Натисніть Commit.
3. Відкрийте вкладку Actions. Збірка «Build APK» запуститься сама (або Run workflow).
4. Через 3–5 хвилин відкрийте завершений запуск, внизу в Artifacts завантажте `golosovyi-pomichnyk-apk` (zip), розпакуйте.
5. Перекиньте `app-debug.apk` на телефон (Viber, пошта, USB), відкрийте і встановіть. Android попросить дозволити встановлення з цього джерела.

## Обмеження

- Постійне слухання розряджає батарею швидше. На деяких телефонах між циклами розпізнавання чутно тихий звук.
- Розпізнавання мовлення дає застосунок Google на телефоні (потрібне оновлене й з українською мовою).
- Для голосу потрібен український голос у Налаштування → Мова → Синтез мовлення.
- Після перезавантаження телефону відкрийте застосунок і запустіть помічника знову (Android забороняє автозапуск мікрофона). Нагадування відновлюються самі.
